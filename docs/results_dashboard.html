Project Development Roadmap

REVIEW 1: Foundation (Completed)
  • Stage 01 (Preprocessing): Basic setup completed (256x256 resizing, Bilinear/NN interpolation, spatial augmentations, ImageNet normalization).
  • Stage 02 (Segmentation): Completed Attention U-Net & Standard U-Net pipelines on Kvasir-SEG with BCE+Dice loss optimization.
  • Stage 04 (Explainability): Partially completed with segmentation-oriented Grad-CAM to visualize model attention.
REVIEW 2: Core Intelligence (Completed)
  • Stage 01 (Preprocessing): Implement advanced preprocessing (CLAHE). Cross-domain evaluation on CVC-ClinicDB completed (EXP-05 to EXP-08).
  • Stage 03 (Classification): Developed ResNet50 binary classifier (Normal vs. Polyp).
  • Stage 04 (Classifier Grad-CAM): Adapted Grad-CAM to explain the classification decision rather than just the segmentation mask.
  • Confidence Score: Implemented a statistically grounded confidence metric representing prediction reliability.
  • Advanced Preprocessing Analysis: Built Laplacian blur detection, color normalization, and quality filtering.
FINAL REVIEW: Integration (Completed)
  • Stage 05 (Reporting): Implemented patient-level frame aggregation and automated diagnostic report generation.
  • Final Application: Built an interactive web application (Flask + HTML/JS/CSS) for end-to-end inference and visualization.
