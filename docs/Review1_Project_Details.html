Main idea of the base paper

The base paper combines:

Attention-guided U-Net + Grad-CAM

The Attention mechanism helps the network focus on relevant regions instead of treating all encoder features equally, while Grad-CAM provides a visual explanation of the model's prediction.

3. What the Base Paper Does

The base-paper approach is essentially:

Colonoscopy Image
        ↓
Encoder
        ↓
Attention Gates
        ↓
Decoder
        ↓
Polyp Segmentation
        ↓
Grad-CAM
        ↓
Explainable Output

The attention gates are used on the skip connections so that relevant features are emphasized before being passed to the decoder.

12. Bottleneck

The bottleneck is the deepest representation of the network. It contains high-level features extracted from the colonoscopy image. Then the decoder reconstructs the segmentation mask.

13. Attention Gate

This is one of the important technical components. Instead of directly passing encoder feature x into the decoder, the feature is filtered using an attention mechanism.

Conceptually:

Encoder Feature x
       +
Gating Signal g
       ↓
  Attention Gate
       ↓
Attention Weights α
       ↓
Filtered Skip Feature
       ↓
Decoder

The attention weight is conceptually:

α = sigmoid(ψ(ReLU(Wg g + Wx x)))

The attention weights range approximately from: 0 → 1. Higher values indicate stronger attention.

14. Decoder

The decoder progressively reconstructs the spatial resolution. It combines:

Upsampled decoder features + attended encoder features

and eventually produces: 1-channel segmentation output representing:

0 = Background
1 = Polyp

15. Loss Function

Our project uses:

BCE + Dice Loss

The total loss is: Ltotal = 1.0 × LBCE + 1.0 × LDice

BCE: Binary Cross Entropy helps with pixel-level classification.

Dice Loss: Helps optimize overlap between Predicted mask ↔ Ground Truth mask. This is particularly useful for segmentation because background can occupy much more area than the lesion.

21. What Each Metric Means

  • Dice: Measures overlap between predicted segmentation and ground truth. Higher = better overlap. (Our Dice: 0.8120)
  • IoU: Measures intersection relative to union. (Our IoU: 0.7307)
  • Precision: Of pixels predicted as lesion, how many were actually lesion pixels. (Our Precision: 0.8532)
  • Recall: How much of the actual lesion region was successfully detected. (Our Recall: 0.8520)
  • Specificity: How well background pixels are correctly identified as background. (Our Specificity: 0.9733)

22. Important Observation About Results

Don't show only the average. The standard deviations are relatively large: Dice SD = 0.2282.

The relatively large standard deviation indicates substantial variation in segmentation performance across individual test images. Therefore, for your PPT, show:

  • Good case: High Dice segmentation.
  • Normal/medium case: Reasonable segmentation.
  • Difficult case: Poor segmentation.

This actually makes your presentation more research-oriented, because you're demonstrating that you evaluated failure cases rather than hiding them.

25. Grad-CAM

Our project implements a segmentation-oriented Grad-CAM. The implementation:

  1. Captures bottleneck activations.
  2. Captures gradients.
  3. Performs forward propagation.
  4. Computes the segmentation output.
  5. Uses the sum of segmentation logits as the score.
  6. Performs backward propagation.
  7. Computes channel weights using global average pooling of gradients.
  8. Weights the activations.
  9. Applies ReLU.
  10. Upsamples the heatmap to 256 × 256.
  11. Normalizes the heatmap.

26. Correct Way to Explain Grad-CAM

Say:

“Grad-CAM provides a post-hoc visual indication of the regions contributing to the segmentation output.”

Do not say:

“Grad-CAM proves that the attention gates are working.” (That is too strong).
